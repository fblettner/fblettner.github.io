# Pricing

The **Pricing** screen is the price book Nomasx-1 uses to estimate the financial risk. One line per `(Component, Metric)`. Each row carries the unit list price, the minimum quantity Oracle imposes on the metric, and the annual support fee.

The [Licensing review](../../licensing-review.md#risk) prices each missing seat and each user of a module no line covers at the *Application User* price of the module plus three years of support, and the Named User Plus beyond a subscription at their own price; the *Minimum* gives the Named User Plus per processor (see [How a contract is counted](../../how-a-contract-is-counted.md#named)).

## Goal of the view

- **Price book input.** Per (Component × Metric), the unit list price and unit support fee.
- **Read by the [Licensing review](../../licensing-review.md#risk)** and the [licence audit report](../../reports/audit-licences.md): list price + 3 × support for each gap.
- **Audit traceability.** Changes to a row should be approved and audit-stamped.

---

## Columns

| Column | Source | What it tells you |
|---|---|---|
| **ID** | `PRC_ID` — internal identifier. | Number of the price line. |
| **Component ID (ID)** · **Component ID** | `PRC_CPT_ID` — the component, and its name. | The component being priced. |
| **Metric ID (ID)** · **Metric ID** | `PRC_MET_ID` — the metric, and its name. | The unit the price applies to. |
| **Price** | `PRC_PRICE` — list price. | Unit list price. |
| **Minimum** | `PRC_MINIMUM` — minimum quantity. | Oracle's minimum for the metric: the Named User Plus per processor (25 for the Enterprise Edition database). |
| **Support** | `PRC_SUPPORT` — yearly support fee. | Per-unit support cost — counted three years in the estimates. |

The *Price List*, *Category*, *Component* and *Metric* columns are hidden by default; **Columns** shows them.

## Edit dialog \{#edit\}

The grid is writable. **Add row** opens an empty form; a click on a row opens it; **Bulk edit** changes the rows in place, in the grid. The form, **Edit · Settings - Licences Pricing** (**New · Settings - Licences Pricing** on a new row), carries **Delete**, **Duplicate**, **Cancel** and **Save**; a new row has **Cancel** and **Save** only.

## Tips & best practices

- **Update the price book at renewal time** — Oracle ships a new technical price list every year. Keeping the numbers current is what makes the financial impact view trustworthy.
- **Remember the *Minimum*** — Oracle imposes a minimum (e.g. 25 NUP per processor on Database EE). The count of a database never goes below the minimum × its processors, whatever the number of users.
- **Cross-reference with [Subscribed licences](../../licenses/subscribed-licences.md)** to detect prices being applied to a metric the contract does not use.
