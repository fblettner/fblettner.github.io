# Components included

The **Components included** screen lists what a licence component includes. A contract line on the component — alone or in a bundle — covers the components it includes too: the [Licensing review](../../licensing-review.md) seats their users on that line instead of counting them on *a module no line covers*.

The screen is delivered with the case Oracle's price list states: **Oracle Technology Foundation for JD Edwards EnterpriseOne** includes **JD Edwards EnterpriseOne Core Tools and Infrastructure** and **Oracle Standard Edition 2**.

Access: **Settings → Licenses → Pricing → Components included**.

## How it is read \{#reading\}

- A line on a component covers itself **and** everything it includes; what an included component includes is followed too.
- The users of an included module take a seat on the line of the component that includes it. Beyond its quantity, they are **missing seats** on that module — no longer a module no line covers.
- On the *Usage* tab of the Licensing review, such a line says what it includes (*Application User · includes Core Tools and Infrastructure, Oracle Standard Edition 2*).

See [How a contract is counted](../../how-a-contract-is-counted.md#includes).

## Tips & best practices

- **Only state what the price list says.** A component included by mistake hides the users of a module that is really missing from the contract.
- **Read the Licensing review again after a change.** The page reads the settings each time it opens.
