# Oracle

The **Oracle** licence page shows, for the Oracle database of a connected application, **each licensable component — the edition, its options and its management packs — found in use or not, against what the contracts subscribe**. Four figures sit on top; the grid lists every component checked, with what it reads: covered, in use with no line, subscribed and not in use.

The technical side of the same database — its options, features, partitions and instances as collected — is on [Database → Oracle](../database/oracle.md); the contract lines are on [Subscribed licences](./subscribed-licences.md).

Open it from **Licences → Oracle**.

## The header \{#header\}

| Control | What it does |
|---|---|
| **Application** | The application whose Oracle database is read, as `id · name`. Only the applications an Oracle database was collected for are offered. The page reopens on the last one. |
| **Read again** | Reads the application again. |

---

## The figures \{#figures\}

| Figure | What it counts |
|---|---|
| **Components checked** | Every Oracle component the collection checked on the database. |
| **In use** | The components found in use. |
| **In use, not subscribed** | Found in use with no contract line for the application. Orange, with the reminder *to qualify before any estimate: an option can be on without being used by the application*. |
| **Subscribed, not in use** | A contract line exists and the component was not found in use. |

---

## Components \{#tab-components\}

One line per component, those in use first.

| Column | What it shows |
|---|---|
| **Component** | The licensable item: *Oracle Enterprise Edition*, *Partitioning*, *Diagnostics Pack*, *Tuning Pack*, *Advanced Compression*… |
| **Category** | Its family in the price list: Oracle Database, Oracle Enterprise Edition Options, Database Enterprise Management, Oracle Others Products. |
| **In use** | *yes* when the collection found it in use on the database. |
| **Subscribed** | The quantity on the contracts that cover the application, added up. |
| **Metric** | The metric of those lines (Processor, Named User Plus…). |
| **Reading** | *in use, subscribed* · *in use, NOT subscribed* · *subscribed, not in use* — empty when the component is neither in use nor subscribed. |

*In use* is what the licence collection found: it asks the database itself, one detection query per component, at each run of **Jobs → Collect licences**.

## Tips & best practices

- **Qualify every *in use, NOT subscribed* line** on [Database → Oracle](../database/oracle.md): the *Features* tab says when the feature was last used, the *Partitions* tab whether a partitioned segment belongs to a vendor schema or to the business.
- **A pack in use with no line** is often a management console that was opened once: check the dates before counting it.
- ***Subscribed, not in use*** lines are the first to discuss at renewal.
- **The figures are an assumption to discuss with Oracle**, never a certified position.
