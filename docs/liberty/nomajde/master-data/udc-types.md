# UDC Types

**JD Edwards data → Master Data → UDC → UDC Types** lists every *User Defined Code* type declared in JD Edwards (F0004): one row per product code and UDC type, with its description. The values of each type are on [UDC Code](./udc-codes.md).

## The grid \{#grid\}

The screen is a read-only list of JD Edwards' UDC types: every type on one page, with search, sort, filters and export, instead of opening the JD Edwards form system by system. A type is created or changed in JD Edwards.

| Column | Source | Content |
|---|---|---|
| **Product code (ID)**, **Product code** | `DTSY` | The system code the type belongs to (`00` general, `01` Address Book, `04` Accounts Payable…) and its name. |
| **User defined codes (ID)**, **User defined codes** | `DTRT` | The type within the product code, and its title. |
| **Description** | `DTDL01` | The description of the type. |

The other columns of F0004 — code length, numeric flag, second line, audit fields — are under **Columns**.

---

## Tips & best practices \{#tips\}

- Filter on **Product code** in the advanced filters to focus on one area — `01` for Address Book, `04` for Accounts Payable, `41` for Inventory.
- The customer's own types sit in the reserved product codes `55` to `59`: a filter on them lists what was added to the standard.
- **Export** gives the catalogue as an Excel file for an audit or a consultant.
