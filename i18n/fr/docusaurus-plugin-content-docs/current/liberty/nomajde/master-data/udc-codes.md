# Codes UDC

**Master Data → UDC → UDC Code** liste les valeurs des types UDC de JD Edwards (F0005) : les codes que les écrans de JD Edwards contrôlent, une ligne par code produit, type UDC et code.

## La grille \{#grid\}

L'écran est une liste en lecture seule : toutes les valeurs de tous les types dans une grille, avec recherche, tri, filtres et export — là où l'écran de JD Edwards montre un type à la fois. Une valeur s'ajoute ou se modifie dans JD Edwards.

| Colonne | Source | Contenu |
|---|---|---|
| **Product code (ID)**, **Product code** | `DRSY` | Le code système du type, et son nom. |
| **User defined codes (ID)**, **User defined codes** | `DRRT` | Le type UDC, et son titre. |
| **User defined code** | `DRKY` | Le code lui-même. |
| **Description**, deuxième description | `DRDL01`, `DRDL02` | Le libellé court affiché dans les écrans et les recherches, et la deuxième ligne. |
| Traitement spécial | `DRSPHD` | Une valeur sur laquelle certains programmes de JD Edwards s'appuient. |
| Codé en dur | `DRHRDC` | `Y` quand des programmes de JD Edwards testent la valeur dans leur code. |
| Date de mise à jour | `DRUPMJ` | La date du dernier changement de la valeur. |

---

## Conseils & bonnes pratiques \{#tips\}

- Filtrer sur **Product code** et **User defined codes** dans les filtres avancés avant **Exécuter** : la table compte des dizaines de milliers de lignes.
- Une valeur codée en dur est testée par les programmes de JD Edwards : elle se modifie avec précaution, dans JD Edwards.
- **Exporter** fournit les valeurs en fichier Excel — pratique pour comparer deux environnements ou relire une liste avec le métier.
