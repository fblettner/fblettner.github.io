# Types UDC

**Données JD Edwards → Données de base → UDC → Types UDC** liste chaque type de *User Defined Code* déclaré dans JD Edwards (F0004) : une ligne par code produit et type UDC, avec sa description. Les valeurs de chaque type se trouvent dans [UDC Code](./udc-codes.md).

## La grille \{#grid\}

L'écran est une liste en lecture seule des types UDC de JD Edwards : tous les types sur une page, avec recherche, tri, filtres et export, au lieu d'ouvrir l'écran de JD Edwards système par système. Un type se crée ou se modifie dans JD Edwards.

| Colonne | Source | Contenu |
|---|---|---|
| **Product code (ID)**, **Product code** | `DTSY` | Le code système auquel appartient le type (`00` général, `01` carnet d'adresses, `04` comptabilité fournisseurs…) et son nom. |
| **User defined codes (ID)**, **User defined codes** | `DTRT` | Le type à l'intérieur du code produit, et son titre. |
| **Description** | `DTDL01` | La description du type. |

Les autres colonnes de F0004 — longueur du code, indicateur numérique, deuxième ligne, champs d'audit — sont accessibles par **Colonnes**.

---

## Conseils & bonnes pratiques \{#tips\}

- Filtrer sur **Product code** dans les filtres avancés pour cibler un domaine — `01` pour le carnet d'adresses, `04` pour la comptabilité fournisseurs, `41` pour les stocks.
- Les types propres au client se trouvent dans les codes produit réservés `55` à `59` : un filtre dessus liste ce qui a été ajouté au standard.
- **Exporter** fournit le catalogue en fichier Excel, pour un audit ou un consultant.
