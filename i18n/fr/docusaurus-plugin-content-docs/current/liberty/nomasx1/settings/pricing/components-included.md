# Composants inclus

L'écran **Composants inclus** recense ce qu'un composant de licence inclut. Une ligne de contrat sur ce composant — seule ou dans un bundle — couvre aussi les composants qu'il inclut : la [revue des licences](../../licensing-review.md) place leurs utilisateurs sur cette ligne au lieu de les compter sur *un module qu'aucune ligne ne couvre*.

L'écran est livré avec le cas que prévoit la liste de prix d'Oracle : **Oracle Technology Foundation for JD Edwards EnterpriseOne** inclut **JD Edwards EnterpriseOne Core Tools and Infrastructure** et **Oracle Standard Edition 2**.

Accès : **Paramètres → Licences → Tarification → Composants inclus**.

## Lecture \{#reading\}

- Une ligne sur un composant couvre ce composant **et** tout ce qu'il inclut ; ce qu'inclut un composant inclus est également pris en compte.
- Les utilisateurs d'un module inclus prennent place sur la ligne du composant qui l'inclut. Au-delà de sa quantité, ce sont des **licences manquantes** sur ce module — et non plus un module qu'aucune ligne ne couvre.
- Dans l'onglet *Utilisation* de la revue des licences, une telle ligne indique ce qu'elle inclut (*Application User · inclut Core Tools and Infrastructure, Oracle Standard Edition 2*).

Voir [Lecture d'un contrat](../../how-a-contract-is-counted.md#includes).

## Boîte de dialogue \{#edit\}

La grille est modifiable. **Ajouter une ligne** ouvre un formulaire vide ; un clic sur une ligne l'ouvre ; **Modifier en lot** modifie les lignes sur place. Le formulaire porte **Supprimer**, **Dupliquer**, **Annuler** et **Enregistrer** ; une nouvelle ligne n'a que **Annuler** et **Enregistrer**. L'écran ne propose pas d'import.

## Conseils & bonnes pratiques

- **Ne déclarer que ce que prévoit la liste de prix.** Un composant inclus à tort masque les utilisateurs d'un module réellement absent du contrat.
- **Relire la revue des licences après une modification.** La page relit les paramètres à chaque ouverture.
