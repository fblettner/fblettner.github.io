# Internationalisation

Deux couches portent du texte dans Liberty Next :

| Couche | Contenu | Langues |
|---|---|---|
| **L'interface** | Boutons, Paramètres, pages Nomaflow, messages. | Anglais et français, livrés avec le framework. |
| **La configuration** | Libellés des données, valeurs de listes, entrées de menu, écrans, actions, onglets de dialogue, saisies préalables, tableaux de bord, questions de départ. | Un libellé par défaut et une traduction par langue, renseignés dans les Paramètres. |

---

## Langue de l'interface \{#interface\}

Chaque utilisateur choisit **EN** ou **FR** dans la barre en haut de la fenêtre. Le choix est conservé dans le navigateur et s'applique aussitôt : menus, en-têtes de colonnes et libellés des listes sont rechargés dans la nouvelle langue.

Chaque requête envoyée par l'application porte cette langue (en-tête `X-Liberty-Lang`). Une requête qui ne la porte pas — un appel direct à l'API — prend la première langue de son en-tête `Accept-Language`, sans la région (`fr-CA` → `fr`), puis la langue par défaut de la configuration.

---

## Traduire la configuration \{#configuration\}

Les éléments traduisibles ont un **libellé** par défaut et une liste de **traductions** — une ligne par code de langue (`fr`, `de`, `es`…), enregistrée dans `l` :

| Élément | Lieu de la traduction |
|---|---|
| **Entrée du dictionnaire** — le libellé d'une donnée, donc de toutes les colonnes qui l'utilisent | Liberty Next → Données → Dictionnaire → Entrées, onglet **Translations**. |
| **Valeur d'énumération** | Liberty Next → Données → Dictionnaire → Énumérations, sur chaque valeur. |
| **Entrée et dossier de menu** | Liberty Next → Écrans → Menus, onglet **Translations** de l'entrée choisie. |
| **Écran** — son libellé (l'onglet, la liste des écrans) et sa description (le titre de la page) | Concepteur d'écran, étape *Ce qu'il est* : **Label translations** sous le libellé, **Description translations** sous la description. |
| **Action** — une entrée du menu de ligne, un bouton de barre d'outils ou d'onglet, une étape d'une chaîne | L'onglet **Translations** de l'action — voir [Actions et cycle de vie](../build/screens/actions-and-lifecycle.md#translations). |
| **Onglet de dialogue** | Concepteur d'écran, étape *Fiche* → **Paramètres de l'onglet** → **Titre dans les autres langues** — voir [Constructeur de dialogue](../build/screens/dialog-builder.md#tab-settings). |
| **Titre d'une saisie préalable** | Le champ **prompt_l** de l'action. |
| **Tableau de bord** — son titre et sa description, les textes d'une carte, un lien, le libellé d'un filtre | Liberty Next → Analyse → Tableaux de bord : le bloc *Dans les autres langues* sous chaque champ — voir [Tableaux de bord](../dashboards.md#languages). |
| **Questions de départ** de l'assistant | Liberty Next → Logique → IA, sélecteur **Langue** — voir [Assistant IA](../ai-assistant.md#settings-ai). |

```toml
[entries.CUSTOMER_STATUS]
label = "Customer status"
l = { fr = "Statut client", de = "Kundenstatus" }
```

Le serveur renvoie chaque texte directement dans la langue de la requête (`fr-FR` se rabat sur `fr`). Sans traduction pour cette langue, le libellé par défaut s'affiche. Les codes de langue s'écrivent en minuscules.

Les en-têtes de colonnes viennent du dictionnaire : une colonne sans libellé propre reprend le libellé traduit de son entrée. Un libellé saisi directement sur une colonne d'écran n'est pas traduit — le laisser vide pour hériter du dictionnaire. Voir [Dictionnaire](../dictionary.md).

---

## Bonnes pratiques

- **Traduire dans le dictionnaire** plutôt que sur chaque écran : une entrée alimente toutes les colonnes de tous les écrans.
- **Écrire les libellés par défaut dans la langue lue par la majorité des utilisateurs**, et ajouter les autres en traductions.
- **Traduire aussi les dossiers de menu** : c'est ce que l'utilisateur lit en premier.
